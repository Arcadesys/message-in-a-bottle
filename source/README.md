# Editorial sources

This folder contains the human-directed source material for the free tabletop edition.

- `introduction.md`: premise, spoiler brief, table setup, clue policy, and calibration.
- `sessions.mjs`: all eight sessions and twenty-four scene cards, with procedures, clues, outcomes, and clocks.
- `appendix.md`: original NPC profiles, node map, clocks, scaling notes, credits, and the full fan notice.
- `handouts.md`: player-facing handout masters and reveal timing.

The checked-in HTML app in `../app/` and printer-friendly PDFs in `../pdf/` are ready to use without rebuilding. To rebuild the two text-first PDFs, run `node scripts/build-pdfs.mjs` from the repository root. The original website also has an illustrated PDF edition and an illustrated campaign walkthrough.

**Provenance:** the original campaign bible and eight unplayed session outlines establish the core story. The free edition adds runnable encounter procedures, names, statistics, handouts, routes, and failure outcomes. No private player questionnaire, private messages, real-person biography, or confidential play notes are included.
