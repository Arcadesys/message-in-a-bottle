# Message in a Bottle

A free, illustrated Savage Worlds campaign module and GM guide in static HTML. Open `index.html` in a browser; no installation, build or network connection is required. Keep `styles.css`, `script.js` and `images/` beside it.

The website includes all eight planned gatherings, GM reveals, prepared antagonist alternatives, branching consequences, the intended homecoming, unfinished decisions and a source bibliography. All campaign text remains visible without JavaScript. Optional controls enlarge text or print the module. Open the “Stat blocks” section for eleven profiles and the session roster.

New AI-assisted illustrations interpret documented plans. Captions distinguish them from source artifacts. Private source snapshots, original player intake, correspondence and personal biographical details are excluded from this package.

The public source repository is https://github.com/Arcadesys/message-in-a-bottle. This illustrated guide is a separate edition alongside the repository’s full scene runner, PDFs and handouts. No private source snapshots or local audit files are included.

The module is a flexible campaign framework. The optional SWADE table reference now provides eleven profiles (four Wild Cards and seven Extras), a roster for all eight sessions, and encounter adjustments for a four-Seasoned-hero baseline. `stat-blocks.md` is a separate offline reference. These additions are unplaytested; maps, detailed task design and other open choices still need preparation. Original campaign facts remain distinct from new module additions.

Savage Worlds is Pinnacle Entertainment Group’s game system; the core rules are required. This unofficial edition is free under Pinnacle’s Fan License.
